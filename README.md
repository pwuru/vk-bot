VK Pizza Bot

Бот для ВКонтакте, который автоматически принимает заказы пиццы из неструктурированных сообщений пользователей. Бот извлекает имя, телефон, адрес, тип пиццы и время доставки с помощью Yandex GPT.

ФУНКЦИОНАЛ:

- Принимает заказы в свободной форме
- Автоматически извлекает данные: имя, телефон, адрес, пицца, время
- Дозапрашивает недостающую информацию
- Хранит историю заказов в базе данных
- Работает через облачный ИИ Yandex GPT

ТЕХНОЛОГИИ:

- Node.js + VK-IO
- MySQL
- Yandex GPT API
- Axios

РАЗВЕРТЫВАНИЕ:

1. Клонируйте репозиторий

git clone https://github.com/ваш-username/vk-pizza-bot.git
cd vk-pizza-bot

2. Установите зависимости

npm install

3. Настройте переменные окружения

Скопируйте .env.example в .env:
cp .env.example .env

Заполните .env своими данными

4. Создайте базу данных

Выполните SQL-скрипт из файла database.sql:
mysql -u root -p < database.sql

5. Запустите бота

node index.js

ПОЛУЧЕНИЕ КЛЮЧЕЙ

Токен VK:

- Зайдите в настройки группы ВКонтакте

- Перейдите в раздел "Работа с API"

- Создайте ключ доступа с правами на сообщения

Ключ Yandex API:

- Зарегистрируйтесь в Yandex Cloud

- Создайте сервисный аккаунт

- Назначьте роль ai.languageModels.user

- Создайте API-ключ с областью yc.ai.languageModels.execute

- Скопируйте folder-id и api-key
